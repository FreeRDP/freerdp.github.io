FreeRDP version 3.33.0 is released:

As usual, the archive can be downloaded from:

https://pub.freerdp.com/releases/

Major feature release, accompanied by the usual bugfix and CVE fixes.
So, what is new:

* webassembly support, now can run from within your browser
* improved SDL client RAILS
* experimental UDP support for direct (without gateway) RDP connections
* unicode keyboard input pipe now supported by all clients (on systems that
  support mkfifo unix style pipes)
* experimental windows shadow server support. It is back from the dead!
* mac OS file clipboard support without FUSE (all clients) 
* Initial support for translation of messages

The influx of pull requests and feedback for bugs/regressions/... was huge, so
we will do a patch release with all the papercuts and bug still in the backlog
soon.
