FreeRDP 3.32.2 has just been released and uploaded to

[https://pub.freerdp.com/releases/](https://pub.freerdp.com/releases/)

Regression, bugfix and security release.
We've been under close scrutiny by various security researchers.
Addressing their findings we've hardened the code base considerably against
malicious client and/or server messages
