FreeRDP 3.31.0 has just been released and uploaded to

[https://pub.freerdp.com/releases/](https://pub.freerdp.com/releases/)

Huge bugfix and security release.

We've received quite a number of smaller and bigger bugfixes and security reports
that have been addressed with this release.
Most important user facing change is a optimization of the YUV decoder which
will result in faster client graphics for AVC/H264 sessions

IMPORTANT: Distributors, please update ASAP, there are severe issues being
           addressed with this release
