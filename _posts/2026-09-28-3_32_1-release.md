FreeRDP 3.32.1 has just been released and uploaded to

[https://pub.freerdp.com/releases/](https://pub.freerdp.com/releases/)

Regression and bugfix release. After the latest hardening a few corner cases
were not covered by regression tests and needed adjustment. Most notably
fragmented static channel PDU were rejected breaking copy & paste for larger data.

* AAudio backend for android
* iOS client updates

## What's Changed
* unit test return check and parameter check fixes (#13479)
* [channels,rdpecam] compare start request against announced media types (#13481)
* [warnings] fix return value checks (#13485)
* [core,gateway] fix http timeout checks (#13484)
* [channels,totalLength] correct and tighthen length checks (#13487)
* [codec] fall back when hardware decoder size is unsupported (#13394)
* [codec,h264] fix ffmpeg hardware acceleration (#13489)
* [winpr,tools] fix makecert -n parsing (#13492)
* [channels,android] add AAudio backends for rdpsnd and audin (#13483)
* [client,common] install aad helpers in libexec (#13490)
* [channels,cliprdr] notify client about empty formats from server (#13496)
* X11 reconnect dialog (#13497)
* [channels,rdpecam] release idle capture devices after a timeout (#13498)
* Gfx checks (#13502, #13511)
* Proxy refine (#13508)
* [ci,deb] add libexec to packaged files (#13510)
* [codec,h264] fix avc444 no-picture handling and decode validation (#13499)
* [client,sdl] fix multimon layout on wlroots compositors (#13507)
* [winpr,clipboard] include null terminator in CF_TEXT size (#13503)
* [client, ios] replace deprecated api to modern api, fix some bugs (#13515, #13512)
* [codec,h264] fix Media Foundation stream change handling and chroma plane offsets
  (#13520, #13522)
* [channels,urbdrc] fix status mapping and descriptor write (#13523)
* [utils,cliprdr] fix regression in contains_dotdot (#13527)
* [winpr,crt] fix ConvertLineEndingToCRLF for leading and trailing line breaks (#13530)
* [codec,dsp] fix opus encode output length (#13531)
* [winpr,cmake] replace check_symbol_exists (#13529)
* Winpr utils image (#13532)
* [winpr,utils] check the bitmap size in 64 bit (#13535)
* [channels,rdpsnd] close the channel when stopping without an own thread (#13536)
* [channels,rdpei] don't close the channel twice after a failed init (#13534)
* Fix software/emulated smartcard logon (WITH_SMARTCARD_EMULATE) on Windows (#13528)
* Final cleanups (#13538)
